<code-playground-react>

Código via <script>

Conteúdo do <script type="text/plain"> é lido como código-fonte.

Código via atributo code

O atributo code aceita o código-fonte e é reativo a setAttribute.

Linguagens

lang="jsx"

JavaScript + JSX. Usa o código default JSX.

lang="tsx"

TypeScript + JSX. Usa o código default TSX com interface e type annotation.

Temas

Atributo theme: dark (padrão), light, dracula, nord.

theme="dark"

theme="light"

theme="dracula"

theme="nord"
